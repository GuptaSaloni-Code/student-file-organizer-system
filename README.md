# Student File Organizer System

A console-based document management system built in Java.
Helps students organize their notes, PDFs, assignments and important documents.

---

## Features

- Add documents with title, subject, type, description and file path
- View all saved documents
- Search documents by title or subject
- Update existing documents by ID
- Delete documents by ID
- Open real files (PDF, images, docs) directly from the program
- Login and Register system with 3-attempt security
- Data saved permanently in text files (no database needed)

---

## Technologies Used

- Java (Core)
- OOP — classes, objects, encapsulation
- ArrayList — in-memory data storage
- Java File I/O — FileWriter, BufferedReader
- Java Desktop API — to open real files
- Git and GitHub - Version Control
